# Idea Reality Check

Проверка конкурентности и уникальности идей через MCP-сервер `idea-reality-mcp`.

## Что делает

Сканирует 6 источников на предмет существующих реализаций идеи:
- **GitHub** — репозитории с похожим описанием
- **Hacker News** — обсуждения и запуски
- **npm** — JS/TS пакеты
- **PyPI** — Python пакеты
- **Product Hunt** — запуски продуктов
- **Stack Overflow** — вопросы и обсуждения

## Когда использовать

Паша просит проверить конкурентность/уникальность идеи — например:
- «Проверь идею AI Code Review»
- «Насколько конкурентна идея ...»
- «Есть ли уже аналоги ...»

**Всегда используй idea-reality-mcp для таких запросов.**

## Инструмент: `idea_check`

Параметры:
- `idea` (string, required) — описание идеи на естественном языке
- `mode` (string, optional) — `"quick"` (GitHub + HN, ~2 сек) или `"deep"` (все 6 источников, дольше)

Для быстрых проверок используй `quick`, для серьёзного анализа — `deep`.

## Формат ответа — СТРОГО

⚠️ **Всегда в таком порядке:**

1. **Результаты MCP:** reality score, sub-scores, источники, top_similars, pivot_hints
2. **Сводный вывод:** интерпретация результатов, специфика рынка, рекомендации

Не смешивать части и не начинать с собственных выводов. MCP-результат всегда первым.

## Ссылки на GitHub-репозитории

**Обязательно** приводи прямые ссылки на найденные GitHub-репозитории из результатов MCP. Формат:

- `[owner/repo](https://github.com/owner/repo)` — краткое описание, звёзды, язык

Если MCP вернул названия репозиториев без полных URL — сконструируй ссылку сам: `https://github.com/<owner>/<repo>`.

## Интерпретация результатов

- **Reality score 0–100** — насколько идея уже реализована рынком
  - 0–20: практически нет аналогов, голубое небо
  - 20–40: есть единичные проекты, ниша свободна
  - 40–60: умеренная конкуренция, есть пространство для дифференциации
  - 60–80: высокая конкуренция, нужен сильный угол
  - 80–100: рынок saturated, делать «ещё один такой же» не стоит
- **top_competitors** — список существующих проектов/продуктов
- **trends** — растёт интерес или падает
- **pivot_suggestions** — рекомендации по изменению угла идеи

## Важно

- MCP-сервер `idea-reality-mcp` должен быть запущен (установлен через uvx)
- Если MCP недоступен — скажи об этом, проверку выполнить не получится
- Всегда показывай reality score в ответе Паше

## Ограничения

- **Никакого дополнительного веб-сёрча** (web_search, web_fetch и т.п.) при проверке идеи — только MCP-запрос `idea_check`. Дополнительный поиск в интернете делай **только если Паша явно попросил** об этом отдельной фразой (например, «погугли ещё», «проверь в поиске», «поищи дополнительно»).

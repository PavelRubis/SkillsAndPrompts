# Yandex Reviews Analyzer

Анализирует отзывы заведения на Яндекс.Картах: собирает до 100 самых новых, фильтрует негативные, категоризирует по степени критичности (средняя/высокая/критичная).

## Триггер

Пользователь кидает ссылку на заведение на `yandex.ru/maps/org/...` или `yandex.com/maps/org/...`.

## Процесс

### 1. Сбор отзывов

В Hermes нет тула `yandex_maps_place_reviews` (это был OpenClaw-плагин). Вместо него — тот же сборщик, запущенный как CLI: плагин `@sharleysoft/openclaw-yandex-maps-places-review` ставится локально, а его хендлер вызывается из скрипта `scripts/fetch-reviews.mjs`. Хост OpenClaw при этом не нужен — от него зависит только `src/index.ts` (регистрация тула).

```bash
cd ~/.hermes/tools/yandex-reviews
node fetch-reviews.mjs "<URL заведения>" 100 > /tmp/yandex-reviews.json
```

- `count` — **обязательно** 100 (если Паша явно не указал другое число)
- Логи pino идут в stderr, в stdout — чистый JSON
- Скрипт печатает `{"sourceUrl","requestedCount","fetchedAt","reviews":[{date,text,url}],"stats":{...}}`

Отзывы уже отсортированы по новизне (новые первыми). Никакой браузерной автоматизации вручную не требуется.

**Важно:** сборщик возвращает только `date`, `text` и `url`. Рейтинг (звёзды) и имя автора **недоступны**.

Установка (один раз, если `~/.hermes/tools/yandex-reviews` ещё нет):

```bash
mkdir -p ~/.hermes/tools/yandex-reviews && cd ~/.hermes/tools/yandex-reviews
npm init -y
npm i @sharleysoft/openclaw-yandex-maps-places-review --no-audit --no-fund
npx playwright install chromium-headless-shell
cp <путь к скиллу>/scripts/fetch-reviews.mjs .
```

Проверено на Hermes: node 24 + playwright headless shell, `captchaReloads: 0`, ~30–60 с на 100 отзывов.

⚠️ **Не пытаться собирать отзывы через `browser_exec`** — Яндекс отдаёт этому браузеру страницу-заглушку (`title: 🐴`, текст `limited`), даже на прямых ссылках `/reviews/`. Работает только Playwright из плагина.

### 2. Фильтрация негативных

Поскольку рейтинг недоступен, негативность определяется **только по тексту отзыва**:

**Явно негативный отзыв** (текст содержит):
- Прямые жалобы: «ужасно», «отвратительно», «разочарование», «не советую», «никому не рекомендую», «кошмар»
- Претензии к качеству: «невкусная еда», «невкусно», «никакая кухня», «еда ужасная», «отравился», «испорченный»
- Проблемы с сервисом: «хамство», «хамский», «нахамил», «обсчитали», «обман», «мошенничество»
- Санитарные проблемы: «грязно», «антисанитария», «насекомые», «тараканы», «волосы», «стекло», «пластик», «осколки»
- Организационные провалы: «долгое ожидание», «ждали час», «ждали 30 минут», «не дождались», «ушли голодные»
- Финансовые претензии: «оверпрайс», «не стоит своих денег», «дорого», «скрытые платежи», «сервисный сбор»

**Нейтральный/позитивный отзыв** (игнорируется):
- Текст преимущественно хвалебный: «понравилось», «вкусно», «рекомендую», «супер», «отлично», «восторг», «классно»
- Даже если есть мелкое замечание среди похвалы — считать позитивным, если позитив явно перевешивает
- Нейтральные: «один раз сходить можно», «ничего особенного», «интересно, но еда не очень»

**Пограничные случаи:**
- Если отзыв содержит и позитив, и негатив в равной мере — классифицировать по преобладающему тону
- Если сомнение — относить к негативным (лучше перестраховаться)

### 3. Категоризация по критичности

| Уровень | Критерии |
|---------|----------|
| 🔴 **Критичная** | Антисанитария, отравление, насекомые/грызуны, инородные предметы в еде (стекло, пластик, осколки), хамство персонала, обсчёт/мошенничество, скрытые платежи, нарушение закона, угрозы безопасности |
| 🟠 **Высокая** | Плохое качество еды/напитков, долгое ожидание (30+ минут), грязно, несоответствие описанию/цене, халатность персонала (потеря брони и т.п.), несколько проблем в одном отзыве, организация на нуле |
| 🟡 **Средняя** | Мелкие неудобства, «могло быть лучше», нестабильность качества, не понравился интерьер/музыка, одноразовая мелкая проблема, субъективные претензии, «оверпрайс», «не стоит своих денег» |

Категоризация — на основе текста, с учётом контекста и серьёзности описания.

### 4. Формат вывода

Для каждого негативного отзыва: **дата как markdown-ссылка на отзыв (поле `url`) + краткое описание (1 предложение)**. Если `url` нет — дата без ссылки. Полные тексты отзывов **не выводятся**.

Формат даты: `YYYY-MM-DD` (ISO-дата приведена к MSK). Пример: `[2026-08-01](url_отзыва)`.

```
🔍 Анализ отзывов: [Название заведения]
Ссылка: [URL страницы отзывов]

Проанализировано: N отзывов (самые новые)
Негативных: M

🔴 КРИТИЧНЫЕ (K):
1. [YYYY-MM-DD](url) — [краткое описание сути претензии]

🟠 ВЫСОКИЕ (L):
...

🟡 СРЕДНИЕ (P):
...
```

- Название заведения — из URL (slug вида `/org/restoran_moskva/`) или из контекста; сборщик имя не возвращает.
- Краткое описание — 1 предложение, суть претензии (например: «Стекло в хачапури, персонал отрицал проблему»).
- Поля «Автор» и «★Рейтинг» исключены, так как сборщик их не возвращает.
- **Полные тексты отзывов не включаются в вывод.**

Если негативных нет: «Среди N последних отзывов негативных не найдено 🔥»

## Зависимости

- Node ≥ 22 и npm
- `~/.hermes/tools/yandex-reviews/` — локальная установка `@sharleysoft/openclaw-yandex-maps-places-review` + `fetch-reviews.mjs`
- Playwright headless shell для этой версии playwright (`npx playwright install chromium-headless-shell`)
- Ни `plugins.entries`, ни `tools.alsoAllow` не нужны — это OpenClaw-специфика

## Notes

- Сборщик использует Playwright и сам обрабатывает скролл, сортировку и извлечение данных.
- Капчи обрабатываются перезагрузкой страницы (счётчик `captchaReloads` в `stats`); если попытки кончились — скрипт падает с ошибкой. Тогда сообщить Паше, что сбор не удался, и предложить прислать отзывы текстом.
- Если у заведения < 100 отзывов — вернутся все доступные.
- Если сборщик когда-нибудь начнёт возвращать рейтинг — обновить секцию «Фильтрация негативных» под звёзды.
- Обновление сборщика: `cd ~/.hermes/tools/yandex-reviews && npm i @sharleysoft/openclaw-yandex-maps-places-review@latest && npx playwright install chromium-headless-shell`

# Yandex Reviews Analyzer

Анализирует отзывы заведения на Яндекс.Картах: собирает до 100 самых новых, фильтрует негативные, категоризирует по степени критичности (средняя/высокая/критичная).

## Триггер

Пользователь кидает ссылку на заведение на `yandex.ru/maps/org/...` или `yandex.com/maps/org/...`.

## Процесс

### 1. Открытие страницы отзывов

- Из полученной ссылки извлечь ID организации и slug (например, `list_i_zerno/119043818189`).
- Открыть в браузере URL отзывов: `https://yandex.com/maps/org/<slug>/<org_id>/reviews/`
- Дождаться загрузки: `wait --load`, затем снапшот для подтверждения.
- **Важно:** Яндекс.Карты — SPA; после открытия reviews-вкладки контент рендерится динамически.

### 2. Сортировка по новизне

⚠️ **Кнопка сортировки НЕ кликается через aria-ref.** Яндекс.Карты используют кастомный DOM-попап (`.rating-ranking-view__popup-line`), который не отражается в accessibility tree снапшота. Обычный `openclaw browser click <ref>` на кнопку «By default» не открывает дропдаун. **Единственный работающий способ — `evaluate` с PointerEvent/MouseEvent диспатчем.**

```js
// Шаг 1: найти кнопку сортировки и открыть попап через PointerEvent
const sortBtn = document.querySelector("div[role=button].rating-ranking-view");
const rect = sortBtn.getBoundingClientRect();
const cx = rect.x + rect.width/2, cy = rect.y + rect.height/2;
sortBtn.dispatchEvent(new PointerEvent("pointerdown", {bubbles:true, cancelable:true, clientX:cx, clientY:cy, pointerId:1, pointerType:"mouse", isPrimary:true}));
sortBtn.dispatchEvent(new MouseEvent("mousedown", {bubbles:true, cancelable:true, clientX:cx, clientY:cy, button:0}));
sortBtn.dispatchEvent(new PointerEvent("pointerup", {bubbles:true, cancelable:true, clientX:cx, clientY:cy, pointerId:1, pointerType:"mouse", isPrimary:true}));
sortBtn.dispatchEvent(new MouseEvent("mouseup", {bubbles:true, cancelable:true, clientX:cx, clientY:cy, button:0}));
sortBtn.dispatchEvent(new MouseEvent("click", {bubbles:true, cancelable:true, clientX:cx, clientY:cy, button:0}));
```

Подождать ~2 секунды (попап рендерится асинхронно), затем кликнуть «New first»:

```js
// Шаг 2: найти опцию "New first" в выпавшем попапе и кликнуть
const newFirst = Array.from(document.querySelectorAll("div")).find(el =>
  el.textContent.trim() === "New first" &&
  el.className.includes("rating-ranking-view__popup-line") &&
  el.offsetParent !== null
);
if (newFirst) newFirst.click();
```

После этого снапшот должен показать кнопку сортировки с текстом «New first». Если нет — повторить шаги 1-2.

**Доступные опции сортировки в попапе:** «By default», «New first», «Negative first», «Positive first».

### 3. Сбор отзывов (до 100)

Яндекс использует бесконечный скролл. Алгоритм:

1. Извлечь отзывы из DOM через `evaluate` — контейнер `.business-reviews-card-view__reviews-container`.
2. Если собрано < 100 отзывов и есть ещё неподгруженные:
   - Скроллить вниз: `evaluate` с `window.scrollBy(0, 5000)`.
   - Ждать подгрузки: `wait --load` или `wait --text`.
   - Повторить извлечение.
3. Остановиться, когда собрано ≥ 100 отзывов ИЛИ два извлечения подряд не добавляют новых.

**Извлечение данных через evaluate:**

Для каждого отзыва (ребёнка контейнера):
- **Автор** — первый `<a>` с непустым текстом внутри элемента отзыва.
- **Дата** — regex `/(January|February|...|December)\s+\d{1,2}/i`.
- **Рейтинг** — из `aria-label` элемента с атрибутом `aria-label*="Rating"`, regex `/(\d)/`.
- **Текст отзыва** — textContent элемента, очищенный от «Level», «Subscribe», «Like», «Dislike», «Share», «More».

Перед извлечением текстов — кликнуть все кнопки «More», чтобы развернуть обрезанные отзывы.

### 4. Фильтрация негативных

Негативный отзыв:
- Рейтинг 1★ или 2★ — всегда негативный.
- Рейтинг 3★ — негативный при наличии в тексте жалоб/проблем/«но»/«к сожалению».
- Рейтинг 4★ или 5★ — НЕ негативный (кроме редких случаев, когда текст содержит явный негатив — оценить по контексту).

### 5. Категоризация по критичности

| Уровень | Критерии |
|---------|----------|
| 🔴 **Критичная** | Антисанитария, отравление, насекомые/грызуны, инородные предметы в еде (стекло, пластик и т.п.), хамство персонала, обсчёт/мошенничество, нарушение закона, угрозы безопасности |
| 🟠 **Высокая** | Плохое качество еды/напитков, долгое ожидание, грязно, несоответствие описанию/цене, халатность персонала (потеря брони и т.п.), несколько проблем в одном отзыве |
| 🟡 **Средняя** | Мелкие неудобства, «могло быть лучше», нестабильность качества, не понравился интерьер/музыка, одноразовая мелкая проблема, субъективные претензии |

Категоризация — на основе текста, с учётом контекста и серьёзности описания.

### 6. Формат вывода

Для каждого негативного отзыва: **краткое описание (1 предложение)**, затем полный текст.

```
🔍 Анализ отзывов: [Название]
📍 [Адрес] | ⭐ [Рейтинг] | [N] отзывов
Ссылка: [URL страницы отзывов]

Проанализировано: N отзывов (самые новые)
Негативных: M

🔴 КРИТИЧНЫЕ (K):
1. [Автор], [Дата], ★[Рейтинг] — [краткое описание]
   > [Полный текст отзыва]

🟠 ВЫСОКИЕ (L):
...

🟡 СРЕДНИЕ (P):
...
```

- Ссылки на конкретные отзывы **не приводятся** (требуют дополнительных кликов, часто недоступны). Вместо этого в шапке даётся общая ссылка на страницу отзывов.
- Краткое описание — 1 предложение, суть претензии (например: «Стекло в хачапури, персонал отрицал проблему»).

Если негативных нет: «Среди N последних отзывов негативных не найдено 🔥»

## Зависимости

- `@openclaw/browser-plugin` (должен быть настроен и работать)

## Notes

- **Почему evaluate, а не aria-ref:** Яндекс.Карты рендерят попапы и дропдауны через кастомные div-элементы (`.popup`, `.rating-ranking-view__popup-line`), которые не отражены в accessibility tree, возвращаемом `browser snapshot`. Команды `browser click <ref>` не вызывают открытие этих попапов. Нужен `evaluate` с `PointerEvent` + `MouseEvent` для симуляции реального клика.
- Яндекс.Карты могут показать капчу при частых запросах. Если снапшот вернул капчу — пауза 5–10 секунд и повтор.
- Если у заведения < 100 отзывов — анализировать все доступные.
- Скролл подгружает ~10–20 отзывов за раз. Для 100 отзывов может потребоваться 5–10 скроллов.
- Перед извлечением текстов — кликнуть все «More» для разворачивания полных текстов.

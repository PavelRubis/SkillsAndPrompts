# Video Analyzer

Транскрибация и разбор видео в Notion: YouTube — через Gemini по `video_url`, локальный файл или файл по облачной ссылке — через ffmpeg + whisper.

## Триггер

- `https://youtube.com/watch?v=...` — полный анализ (транскрибация + саммари)
- `https://youtube.com/watch?v=... транскрибация` — только транскрибация
- `https://youtube.com/watch?v=... саммари` — только саммари
- **Файл/ссылка на файл** (Telegram, Яндекс.Диск, Drive) + «проанализируй», «сделай чек-лист», «конспект» — идти в раздел «Большое локальное видео» ниже
- «дай таймкоды для ...» — таймкоды берутся ТОЛЬКО из whisper-сегментов (`verbose_json`), см. тот же раздел

Слова могут быть в любом месте сообщения (до или после ссылки).

## Workflow

### 1. Получить длительность видео

**Primary:** yt-dlp по абсолютному пути `~/.hermes/tools/bin/yt-dlp`

```bash
~/.hermes/tools/bin/yt-dlp --print duration_string "URL"
```

Если бинарника нет — поставить:

```bash
mkdir -p ~/.hermes/tools/bin
curl -sL "https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp_linux" -o ~/.hermes/tools/bin/yt-dlp
chmod +x ~/.hermes/tools/bin/yt-dlp
```

(В PATH его нет и он не сохраняется между вызовами — всегда вызывать по полному пути.)

**Fallback:** YouTube oEmbed

```
https://www.youtube.com/oembed?url=URL&format=json
```

через `web_extract`; длительность в oEmbed есть не всегда.

⚠️ yt-dlp может писать в stderr предупреждение `No supported JavaScript runtime could be found` — это **не фатально**, метаданные всё равно печатаются в stdout. Не считать ошибкой. Результат забирать через `tail -1` (в stdout бывает лишний шум).

### 2. Выбрать модель

- Длительность **≤ 30 минут**: `google/gemini-3.1-pro-preview`
- Длительность **30–60 минут**: `google/gemini-3.5-flash`
- Длительность **> 60 минут**: `google/gemini-3-flash-preview`

**Фолбек-цепочка** (при ошибке/отказе — следующая модель):
1. `google/gemini-3.5-flash`
2. `google/gemini-3-flash-preview`

Если модель отвалилась — свериться со списком доступных: `curl -s https://openrouter.ai/api/v1/models | jq -r '.data[].id' | grep gemini`.

### 3. Транскрибация (запрос 1 к Gemini)

**Endpoint:** `POST https://openrouter.ai/api/v1/chat/completions`

**Headers:**
- `Authorization: Bearer $OPENROUTER_API_KEY`
- `Content-Type: application/json`
- `HTTP-Referer: https://hermes-agent.nousresearch.com`
- `X-Title: Hermes`

**Body:**
```json
{
  "model": "<выбранная модель>",
  "messages": [{
    "role": "user",
    "content": [
      {"type": "text", "text": "Сделай подробную транскрибацию этого видео. Отформатируй в виде хорошо структурированного Markdown: выдели основные темы заголовками, используй списки для перечисления фактов и аргументов, разбей на смысловые блоки. Если в видеоряде есть важная визуальная информация (графики, карты, демонстрации, слайды, фотографии), опиши её в начале соответствующего блока *курсивом*. Указывай таймкоды в формате [MM:SS] для каждого блока. Ответь на русском языке."},
      {"type": "video_url", "video_url": {"url": "<YOUTUBE_URL>"}}
    ]
  }]
}
```

Ответ — `choices[0].message.content`.

⚠️ Запрос с `video_url` реально обрабатывается минуты (Gemini смотрит видеоряд). Таймаут ≥ 900–1800 с; это не «зависание». В `terminal` держать это в фоне (`background=true, notify=true`) или ставить `timeout` явно.

**Один скрипт на оба запроса.** Писать транскрипт и саммари в отдельные файлы скрэтча (`<slug>_transcript.md`, `<slug>_summary.md`) сразу после получения ответа, а скрипт держать в фоне и ждать через `process_manage wait` (лимит ожидания клампится — опрашивать повторно). Тогда транскрипт не теряется, если второй запрос упадёт или сессия прервётся, а в Notion и в чат идёт текст из файлов, а не из контекста.

### 4. Саммаризация (запрос 2 к Gemini)

Тот же эндпоинт, но текст транскрибации **без** `video_url` (дешевле — без видео-токенов).

```json
{
  "model": "<та же модель>",
  "messages": [{
    "role": "user",
    "content": "Сделай краткое, но содержательное саммари следующей транскрибации видео. Отформатируй в виде структурированного Markdown: ключевые тезисы, главные выводы, важные детали. Сгруппируй по темам. Ответь на русском языке.\n\nТранскрибация:\n<TRANSCRIPT_TEXT>"
  }]
}
```

### 5. Сохранить в Notion

Создать страницу в датасорсе с `Тип1 = Конспект`.

**Название страницы** — через yt-dlp:
```bash
~/.hermes/tools/bin/yt-dlp --print title "URL" | tail -1
```

**Структура children** (порядок сверху вниз):
- Paragraph со ссылкой на оригинальное видео
- Toggle «📋 Саммари» → текст саммари
- Toggle «📝 Транскрибация» → полный текст транскрибации

⚠️ Транскрибация бывает длинной → разбивать на paragraph/heading_3 блоки по ~2000 символов.

**Готовый скрипт:** `scripts/notion_md_blocks.py --title ... --url ... --summary s.md --transcript t.md` — конвертирует Markdown в блоки, создаёт страницу с обоими toggles и дозаписывает хвосты внутрь нужного toggle. Не переписывать руками.

⚠️ **Контент кладётся ВНУТРЬ toggle, а не в page children.** Токен Notion создаёт и читает, но на `PATCH /v1/blocks/{id}` и `DELETE /v1/blocks/{id}` отдаёт 403 — переделать структуру после создания не получится, страница останется с плоской простынёй на верхнем уровне. Хвосты длинного контента дозаписывать в `PATCH /v1/blocks/{toggle_id}/children` (id toggle достать из `GET /v1/blocks/{page_id}/children`), пачками ≤95 блоков.

Детали Notion API — в `references/notion-api.md`.

### 6. Ответ в чат

Hermes сам доставляет финальный ответ в Telegram-чат Паши — отдельный механизм отправки не нужен (в OpenClaw это делал канал сам, здесь это просто текст ответа).

**Видео < 10 минут:** три части в одном ответе (или несколькими сообщениями, если не влезает):
1. Полный текст транскрибации
2. Текст саммари
3. Ссылка на Notion-заметку

**Видео ≥ 10 минут:** один ответ — саммари + ссылка на Notion-заметку.

⚠️ Лимит сообщения Telegram — 4096 символов. Саммари часто длиннее → сжать до ~3500–3800 символов (главные выводы + тезисы по темам + цифры), ссылку на Notion оставить. Если совсем не влезает — сохранить полный текст в файл и отдать через `MEDIA:`.

## Большое локальное видео / файл по облачной ссылке

Gemini-путь с `video_url` работает только с публично доступным URL. Файл (Telegram, Яндекс.Диск, Drive, локальный) обрабатывать локально: ffmpeg → нарезка → whisper. Рабочая связка — `scripts/chunked_whisper.sh`.

### 1. Скачать по публичной ссылке

Яндекс.Диск — через API, не через браузер и не через веб-страницу:

```bash
DL=$(curl -s -G "https://cloud-api.yandex.net/v1/disk/public/resources/download" \
  --data-urlencode "public_key=<ссылка>" \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['href'])")
curl -L --fail -sS --retry 5 --retry-all-errors -C - -o video.mp4 "$DL"
```

- `public/resources` и `public/resources/download` принимают ссылки любого вида (`/d/...`, `/i/...`, `yadi.sk/...`) — отдельный эндпоинт на каждый тип не нужен.
- `curl: (56) Recv failure` посередине — не повод начинать заново: `--retry-all-errors -C -` докачивает с места обрыва.
- `{"error":"DiskNotFoundError"}` = файл удалён или ссылка перевыпущена. Перекачка невозможна — просить новую ссылку; таймкоды и пункты заново не выдумывать.
- Сверять `md5`/`size` из `public/resources` с локальным файлом — так подтверждается, что новая ссылка ведёт на то же видео (и что анализ шёл по исходнику).

### 2. Аудио и нарезка

`scripts/chunked_whisper.sh <video>` — извлекает mp3 24 kbps mono 16 kHz и режет по 10 минут: ~1.8 МБ на чанк, лимит whisper 25 МБ на файл держится с большим запасом. 84 минуты → 9 чанков, ~30 с на чанк.

### 3. Транскрибация

`POST https://openrouter.ai/api/v1/audio/transcriptions`, `model=openai/whisper-large-v3-turbo`, multipart `file=@`, ключ `$OPENROUTER_API_KEY` из `~/.hermes/.env`.

⚠️ Всегда `response_format=verbose_json`, а не `json`: без посегментных `start/end` точные таймкоды потом не восстановить. Один лишний флаг экономит повторное скачивание всего видео.

### 4. Таймкоды

Абсолютное время = `номер_чанка * 600 + segment.start`. Сложить все сегменты в один список и искать по нему фразы (regex по тексту сегмента) — тогда ответ «дай таймкод для пункта X» точный до секунд.

⚠️ Интерполяция по доле символов в тексте чанка даёт ±1–1.5 мин — годится только как временная затычка, и выдавать её надо ЯВНО помеченной («оценка ±1–1.5 мин»), не как таймкод.

### 5. Сон, фон и чужая речь

Whisper на тишине и на фоновом звуке выдаёт галлюцинации: «Thank you. Thank you...», «Спасибо за просмотр», «Субтитры сделал DimaTorzok», обрывки чужого ролика. Это не контент:

- найти границы содержательной части (первый осмысленный сегмент, последний) и сказать Паше прямо, какие участки пустые;
- при сведении транскрипта в файл такие чанки не включать — иначе в чек-лист попадёт «ремонт квартиры» вместо код-ревью;
- там, где речь тихая, whisper может отдать только «...» — значит, часть ревью потеряна, об этом тоже сказать, а не додумывать.

### 6. Видеоряд

Кадры только точечно: `ffmpeg -vf "fps=1/60,scale=1280:-1"` даёт 1 кадр в минуту, и смотреть `vision_analyze` лишь там, где по речи обсуждают документ/схему/UI (по кадру можно прочитать текст заметки и сверить с транскриптом). Весь поток кадров не грузить — забьёт контекст.

### 7. Не удалять исходник до конца задачи

«Дай таймкоды», «а вот этот пункт», уточнения — идут ПОСЛЕ первого ответа, а перекачка может оказаться невозможной (ссылка уже мертва, файл удалён). Скрэтч с видео/аудио/чанками чистить только когда Паша подтвердил, что всё нужное получено.

## API-ключи

### OpenRouter

Ключ уже есть в окружении Hermes: `$OPENROUTER_API_KEY` (он же в `~/.hermes/.env`, строка `OPENROUTER_API_KEY=...`).

```bash
export OPENROUTER_API_KEY="${OPENROUTER_API_KEY:-$(grep -m1 '^OPENROUTER_API_KEY=' ~/.hermes/.env | cut -d= -f2-)}"
```

⚠️ **Не выводить ключ в чат/логи** — передавать только в заголовок Authorization. Прежние источники из OpenClaw-версии (`~/.openclaw/agents/main/agent/auth-profiles.json`, SQLite `auth_profile_store`, `memorySearch.remote.apiKey`) в Hermes не существуют — не искать их.

### Notion

```bash
export NOTION_API_TOKEN="$(cat ~/.hermes/state/.notion_token)"
```

## Edge cases

- Видео без субтитров — Gemini анализирует аудиодорожку (работает)
- 401 Unauthorized от OpenRouter → ключ берётся не оттуда; источник — `$OPENROUTER_API_KEY` / `~/.hermes/.env`
- Ошибка API — перейти к следующей модели из фолбек-цепочки
- yt-dlp недоступен — использовать oEmbed; если и он не дал длительность — считать видео коротким
- **Токен Notion: read + create только.** `PATCH`/`DELETE` блоков и страниц → 403 (проверено). Значит: структуру, порядок и вложенность блоков проверять ДО `POST /v1/pages`, а не после; кривую страницу исправить нельзя — только создать новую рядом и сказать об этом. Существующие конспекты не трогать
- **Пункт мог прийти не из видео.** Прежде чем искать таймкод, проверить, есть ли фраза во всех сегментах: часть пунктов чек-листа берётся из соседних заметок (ТЗ, старые разборы). Честно сказать «в видео не проговаривалось, источник — заметка X» вместо похожего таймкода
- **Соседние заметки читать перед созданием новой.** По теме обычно уже есть страница с `to_do` (частично отмеченными) — дублировать её нельзя, а сверка помогает правильно разделить пункты и сохранить формулировки
- **Скрипт:** `scripts/chunked_whisper.sh` — полный цикл аудио → чанки → whisper-сегменты; `--timeline` собирает сводный транскрипт с абсолютными таймкодами

# Промпты для настройки AI

Этот репозиторий содержит мои наборы инструкций (промптов) для настройки поведения больших языковых моделей (LLM).

Промпты включают в себя требования к:
*   **Языку общения**
*   **Навыкам AI**
*   **Источникам информации**
*   **Анализу вопросов**
*   **Формату ответов**

Файлы в директории `Completions/` содержат конкретные инструкции для каждой платформы:
*   `Completions/ChatGPT.md` - Инструкции для настройки AI при использовании с ChatGPT.
*   `Completions/OpenWebUI.md` - Инструкции для настройки AI при использовании с OpenWebUI.

Эти промпты помогают адаптировать поведение AI для более эффективного взаимодействия и получения релевантных ответов в соответствии с заданными требованиями.
